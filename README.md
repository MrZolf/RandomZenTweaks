# RandomZenTweaks

A modular [Sine](https://github.com/CosmoCreeper/Sine) mod for Zen Browser – a collection of small tweaks, each one can be toggled on/off in the mod's settings.

## Modules

### Essentials mute button
- Mute/unmute button on pinned **essential** tabs, shown on hover.
- Choose any of the 4 corners (top/bottom, left/right).
- Optionally always visible while the tab is muted.
- Positioned relative to the tile, so it works with and without *Big Essentials*.

### Essentials sound visualizer
- Small animated equalizer on essential tabs that are playing sound.
- Color: monochrome or matched to the Zen accent color.
- Respects `prefers-reduced-motion`.

## Installation
1. Zen Settings → Sine → *Install from GitHub*.
2. Paste: `MrZolf/RandomZenTweaks`
3. Restart the browser and configure modules in the mod's settings.
