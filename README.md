# RandomZenTweaks

**PL:** Modułowy mod [Sine](https://github.com/CosmoCreeper/Sine) dla przeglądarki Zen – zestaw drobnych poprawek. Każdy moduł można włączyć lub wyłączyć w ustawieniach; wyłączony moduł niczego nie zmienia.
**EN:** A modular [Sine](https://github.com/CosmoCreeper/Sine) mod for Zen Browser – a collection of small tweaks. Each module can be toggled in settings; a disabled module changes nothing.

## Modules / Moduły

### Essentials: mute button and visualizer / przycisk wyciszania i wizualizator

| Setting / Ustawienie | Options / Opcje |
|---|---|
| Mute icon position / Pozycja ikony wyciszenia | 4 corners of the whole tile / 4 rogi całego kafelka |
| Mute icon style / Styl ikony | Light (default) / Dark (inverted) – Jasna / Ciemna |
| Visualizer color / Kolor wizualizatora | Monochrome / Zen accent – Monochromatyczny / Kolor Zen |
| Visualizer width / Szerokość wizualizatora | Small / Medium / Large (full tile) – Mała / Średnia / Duża |

- The mute icon appears on hover, and stays visible while the tab is muted. / Ikona pojawia się po najechaniu i jest widoczna cały czas, gdy karta jest wyciszona.
- Works with and without *Big Essentials*. / Działa z rozszerzeniem *Big Essentials* i bez niego.
- Respects `prefers-reduced-motion`.

## Installation / Instalacja
1. Zen → Settings / Ustawienia → Sine Mods → install from GitHub / instalacja z GitHuba.
2. `MrZolf/RandomZenTweaks`
3. Restart, open the mod's settings and enable the module. / Zrestartuj, otwórz ustawienia moda i włącz moduł.

## Contributing rule / Zasada
Every new user-visible text (setting labels, dropdown options) must be written in both Polish and English.
Każdy nowy tekst widoczny dla użytkownika (etykiety, opcje) musi być po polsku i po angielsku.
